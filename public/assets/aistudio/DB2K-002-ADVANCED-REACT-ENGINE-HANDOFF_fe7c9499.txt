WHAT DEBOOGER IS
Debooger is a browser-based viewer and diagnostic workspace. The user opens one HTML file, then uploads HTML, individual source files, complete folders, project ZIPs, or prebuilt applications. Debooger inspects the uploaded file tree, identifies the project type, resolves a usable entry point, previews the application in an isolated viewer, lets the user inspect/edit content, reports runtime/compile/audit problems, and can export files. It must work when opened from local device storage as far as the browser permits, as well as on a normal static website. GitHub integration exists for optional publishing, but React compilation and preview MUST NOT depend on GitHub, a repository, or GitHub Pages.
